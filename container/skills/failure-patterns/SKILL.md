# Failure Patterns

Your group maintains a `failure-patterns.md` file in the group root that tracks common error patterns from past conversations.

## When to use
- Before starting work that has failed before (check patterns first)
- When encountering an error (check if it's a known pattern)
- When planning a complex task (review relevant failure categories)

## How to use
1. Read `/workspace/group/failure-patterns.md` if it exists
2. Check if your current task matches any known failure categories
3. Apply the recovery hints proactively
4. If you encounter a new error type not in the patterns file, document it in your response so the host can learn from it
