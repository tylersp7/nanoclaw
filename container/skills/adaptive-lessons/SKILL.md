# Adaptive Lessons

Your group maintains a `lessons.md` file that captures patterns from past conversations — what approaches work, what to avoid, and user preferences.

## When to use
- At the start of any task: check lessons for relevant guidance
- When encountering an error: check avoidance lessons
- When making style/format decisions: check preference lessons

## How to use
1. Read `/workspace/group/lessons.md` if it exists
2. Lessons with higher reinforcement counts (seen Nx) are more reliable
3. Apply relevant lessons proactively — don't wait for problems
4. If you discover a new pattern, mention it in your response so the system can learn
