# Proactive Insights

Your group may have a `pending-insights.md` file with observations the learning system wants you to surface.

## When to Check
- At the start of each session (after reading other context)
- The file is lightweight — quick to scan

## How to Deliver Insights
1. Read `/workspace/group/pending-insights.md` if it exists
2. Pick the highest-priority undelivered insight
3. Mention it naturally in conversation — don't force it
4. Integrate it into your response rather than presenting it as a separate "alert"

### Good delivery:
"By the way, I noticed your conversation quality has improved to 0.85 this week — the changes we made to error handling are paying off."

### Bad delivery:
"PROACTIVE INSIGHT ALERT: Quality score is 0.85."

## Priority Guidelines
- **High**: Mention at the first natural opportunity
- **Medium**: Mention if relevant to current conversation, otherwise skip
- **Low**: Only mention if there's a natural opening and no other priorities

## After Delivery
The insight will be automatically marked as delivered by the host system on the next scan. You don't need to manage this — just mention it naturally.

## If No Insights
If the file doesn't exist or has no pending insights, do nothing. Don't mention the absence of insights.
