# Learning Digest

Your group maintains a `learning-digest.md` with weekly metrics showing how the learning system is performing over time.

## When to use
- When the user asks about trends or progress
- When evaluating whether the learning system is helping
- When deciding what areas need attention

## How to use
1. Read `/workspace/group/learning-digest.md` if it exists
2. Look at trend arrows to identify improving vs degrading areas
3. Follow recommendations for areas needing attention
4. Compare current metrics to previous weeks for context
