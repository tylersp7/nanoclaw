# Quality Trends

Your group maintains a `quality-trends.md` file tracking conversation quality over time.

## When to use
- When evaluating your own performance
- When the user asks about conversation quality
- When identifying areas for improvement

## How to use
1. Read `/workspace/group/quality-trends.md` if it exists
2. Low signal scores indicate specific improvement areas:
   - Low completion → tasks ending prematurely or erroring out
   - Low efficiency → conversations running too long
   - Low tool success → tools failing frequently
   - Low user satisfaction → user corrections or complaints
   - Low resolution → tasks not reaching completion
3. Focus improvement efforts on the lowest-scoring signals
