# Skill Effectiveness

Your group maintains a `skill-effectiveness.md` report tracking which skills work well and which don't.

## When to use
- When planning a complex task: check which skills are most effective for similar work
- When a task isn't going well: check if the skills you're using have low success rates
- When exploring capabilities: check unused skills that might help

## How to use
1. Read `/workspace/group/skill-effectiveness.md` if it exists
2. Prefer skills with high success rates for critical tasks
3. Try unused skills when stuck — they may offer untapped capabilities
4. If a skill consistently underperforms, avoid relying on it heavily
